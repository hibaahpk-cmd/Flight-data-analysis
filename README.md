# Flight-data-analysis
Flight Data Analysis using Power BI
## Project Overview

This project focuses on analyzing flight data using Power BI to identify flight cancellations, delays, and route performance.
The dashboard provides useful insights into flight operations through interactive visualizations and key performance indicators (KPIs).
## Project Objectives

- Analyze overall flight operations.
- Identify the total number of flights and cancelled flights.
- Calculate the flight cancellation rate.
- Analyze flight delays and identify major causes.
- Identify the most delayed flight routes.
- Present meaningful insights using interactive Power BI dashboards.
## Tools & Technologies

- Power BI – Data Visualization, Data Analysis, KPI Creation and Interactive Dashboard Development.
## Key Performance Indicators (KPIs)
Total Flights
Total Cancelled Flights
Cancellation Rate
Active Flights
## Dashboard Analysis
1. Flight Cancellation Analysis
This dashboard provides insights into flight cancellations through:
Cancelled Flights by Airline
Cancellation Trends by Month
Cancellation Analysis by Airport
Overall Cancellation Rate
2. Flight Delay Analysis
This dashboard focuses on understanding flight delays through:
Average Departure Delay
Average Arrival Delay
Top 10 Most Delayed Routes
Delay Analysis by Airline
Delay Trends by Month
## Key Insights
The analysis aims to identify:
Airlines with higher cancellation numbers.
Changes in cancellation trends over time.
Routes experiencing significant delays.
Patterns in flight operational performance.
